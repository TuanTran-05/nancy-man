## Brand & Style

EduTrack is a smart education management platform built for Vietnamese schools. Its brand personality is **professional yet approachable** — combining the rigor expected of an administrative tool with a modern, friendly warmth that makes daily use feel effortless. The visual language draws from the best of SaaS dashboard design: clean data hierarchy, generous whitespace, and purposeful motion.

The design philosophy is **"Ambient Intelligence"** — the interface should feel quietly competent, surfacing the right information without visual clutter. Decorative elements are restrained but intentional: soft gradient washes in the corners of the viewport provide a sense of depth and vitality without competing with data. The overall impression is akin to looking through a clean window onto a well-organized workspace.

## Colors

The palette is built on a **Professional Blue** anchor that signals trust, technology, and reliability — critical for an education platform handling student data. A secondary **Warm Orange** accent injects energy and approachability, used sparingly for decorative gradients and accent moments.

- **Primary Blue (#3b82f6):** The dominant action color. All CTAs, active navigation states, focus rings, and interactive highlights use this hue. A darker variant (#2563eb) is used for hover states and text links, while lighter tints (#dbeafe, #eff6ff) serve as tonal backgrounds for active states.
- **Surface Strategy:** The main page background is not flat — it uses a multi-point radial gradient layering soft blue and warm orange washes at each corner, overlaid on a near-white base (#f5f7fb → #ffffff → #f6f9ff). This creates a gentle "watercolor" effect that makes the plain white cards appear to float.
- **Semantic Colors:** Green (#10b981) for success and active states, Amber (#f59e0b) for warnings and paused states, Red (#ef4444) for errors and danger, Purple (#8b5cf6) for ranking and special metrics. Each semantic color has a corresponding light tint background for badge usage.
- **Neutral Slate:** A comprehensive gray palette derived from Tailwind's Slate scale. Text ranges from near-black (#1a2035) for headings through medium (#334155, #64748b) for body and muted text, to light (#94a3b8) for subtle labels. Borders use desaturated blue-grays (#e5e9f0, #eef2f7).
- **Role Colors:** Each user role receives a distinct avatar background — Slate for Admin, Blue for Teacher, Emerald for Student, Amber for Parent, Rose for Accounting, Teal for Level Manager — creating instant visual recognition without additional labels.

### Dark Mode

Dark mode inverts the neutral palette to Slate 900 (#0f172a) backgrounds with Slate 800 (#1e293b) card surfaces. Blue remains the primary but shifts to a lighter value (#60a5fa) for accessibility. Borders use semi-transparent slate (rgba(51, 65, 85, 0.5)) to maintain subtlety. The gradient background washes are suppressed, replaced by a solid dark surface to reduce eye strain.

## Typography

**Inter** serves as the universal typeface, chosen for its exceptional legibility at small sizes, extensive weight range (300–800), and neutral geometric character that avoids cultural bias — important for a bilingual (Vietnamese/English) interface.

- **Display (32px/800):** Used for the loading screen app name and large hero greetings. Letter-spacing is tightened (-0.02em) to create visual density.
- **Headlines (22–26px/700):** Page titles and section headers. Tight tracking (-0.01em) gives them a compact, editorial quality.
- **Body (13–16px/400–500):** The workhorse range. Medium weight (500) is preferred for body text in data-heavy contexts to maintain readability against busy backgrounds.
- **Labels (10–14px/700–800):** Used for badges, status indicators, tab labels, and metadata. Small labels use extra-wide letter-spacing (0.05–0.1em) and uppercase transforms for maximum scannability.
- **Monospaced:** Student/Parent ID codes are displayed in the system mono font with widest tracking for clarity during data entry.

## Layout & Spacing

The layout follows a **sidebar + header shell** pattern. The sidebar provides persistent navigation on the left, with a top header bar containing utility actions (clock, notifications, profile).

- **Grid:** Content areas use responsive CSS grid — typically 1 column on mobile, 2 on tablet, 3–4 on desktop for card grids. The base spacing unit is 4px with an 8px rhythm for most component gaps.
- **Whitespace Philosophy:** Generous. Section gaps use 32px, card grids use 24px gaps, and internal card padding ranges from 20–32px. This "breathing room" is essential to the premium feel.
- **Sidebar:** 280px expanded, 80px collapsed (icon-only). Transitions use CSS `transition-all duration-300 ease-in-out`. On mobile (<1024px), the sidebar slides in as an overlay with a backdrop blur.
- **Header:** Fixed 68px height. Contains the hamburger toggle (mobile only), a live clock badge, notification bell, and dark mode toggle.
- **Content Area:** Full remaining width with internal padding of 16px (mobile) to 32px (desktop). Pages use `space-y-8` vertical rhythm between major sections.

## Elevation & Depth

Elevation in EduTrack is achieved through a layered combination of **borders, shadows, and tonal shifts** rather than heavy drop shadows. The interface feels flat-but-layered.

- **Level 0 (Page Background):** The gradient-washed canvas. Decorative dot patterns are overlaid at very low opacity (0.3–0.34) in the corners to add subtle texture.
- **Level 1 (Cards):** White (#ffffff) surfaces with a 1px border (#eef2f7) and a soft shadow (`0 1px 2px rgba(0,0,0,0.04)`). This is the default resting state for all content panels.
- **Level 2 (Elevated Cards/Panels):** Deeper shadow (`0 16px 44px rgba(15,23,42,0.07)`) used for admin metric cards and overview panels. Hover state intensifies to `0 20px 56px rgba(15,23,42,0.11)`.
- **Level 3 (Modals/Overlays):** Full `shadow-xl` with a darkened backdrop (`rgba(15, 23, 42, 0.50)`) and `backdrop-blur: 4px`. Modals enter with a scale-up animation from 0.95 to reinforce the "lifting" metaphor.
- **Level 4 (Login/Hero Containers):** The login card uses `shadow-2xl` — the heaviest shadow — to feel monumental and authoritative against the atmospheric background.

## Shapes

The shape language is **consistently rounded** to convey friendliness and approachability while maintaining a professional edge. Rounding values scale with component importance.

- **Small Controls (badges, scrollbar):** `rounded-full` (9999px) for pill shapes and `rounded-lg` (1rem) for small buttons.
- **Standard Cards:** `rounded-2xl` (1.5rem) is the baseline for all content cards and modals.
- **Hero Elements:** `rounded-3xl` (2rem) for student greeting banners and `rounded-[2.5rem]` for the login container — the most generous rounding in the system.
- **Icon Containers:** `rounded-2xl` for 48px icon boxes, creating a softened square that echoes the card corners.
- **Inputs:** `rounded-xl` (1.25rem) for form fields, slightly less rounded than cards to create visual hierarchy.
- **Sidebar Items:** `rounded-xl` with the active indicator using an asymmetric `0 4px 4px 0` radius on the left edge bar.

### Cards

Content cards (`card-content`) use `rounded-2xl` with a 1px border and `shadow-sm`. Metric stat cards feature an icon container (colored tonal background + icon) alongside stacked label/value text. On hover, cards lift 4px upward and gain a deeper shadow, providing tactile feedback. The admin dashboard uses elevated variants (`shadow-lg`) for a denser, more data-rich aesthetic.

### Buttons & Inputs

Primary action buttons use `#2563eb` (Blue 600) with white text, `rounded-xl`, and a dramatic blue-tinted shadow (`shadow-blue-100`) that glows beneath the button. Hover darkens to Blue 700 and intensifies the shadow. An `active:scale-[0.98]` press effect adds physical responsiveness. Ghost buttons are transparent with subtle hover fills. Input fields use the page background color with a 1px border, gaining a 2px blue focus ring on interaction.

### Modals

All modals follow a consistent pattern: centered on screen, `max-w-sm` to `max-w-2xl` width, `rounded-2xl`, white background with a two-zone layout — content area on top with `p-6` and a footer action bar on a `bg-slate-50` background with `border-t`. The overlay uses `bg-slate-900/50` with `backdrop-blur-sm`. Entry animation is `scale: 0.95 → 1` over 200ms.

### Navigation & Tabs

Tab bars use a contained style: a tinted background container (`bg-slate-100`, `rounded-xl`, `p-1`) with tabs that gain a white background, shadow, and blue text color when active. The sidebar uses a layout-animated background highlight (`bg-blue-50`) with a spring transition (`stiffness: 350, damping: 30`) that smoothly follows the active item, creating a liquid navigation feel.

## Motion & Animation

Motion is integral to EduTrack's personality. Every page transition, list entry, and hover interaction is animated, but always with restraint — motion serves comprehension, never decoration.

- **Page Transitions:** Fade + vertical slide (`opacity: 0, y: 12 → opacity: 1, y: 0`) over 200ms. Pages exit symmetrically upward.
- **Staggered Entry:** Card grids use `staggerChildren: 50ms` with each card entering from `y: 20` via a spring animation (`stiffness: 300, damping: 24`).
- **Hover Micro-interactions:** Cards lift `y: -4` with `stiffness: 400, damping: 17`. Buttons use `active:scale-[0.98]` for a press-down feel.
- **Loading States:** The app loading screen uses a pulsing logo (scale 0.95↔1 over 2s) and three bouncing dots (staggered 0.15s each), branded in primary blue.
- **Global Color Transitions:** All elements inherit a 150ms color/background transition (`cubic-bezier(0.4, 0, 0.2, 1)`) for seamless theme switching and hover effects.
- **Sidebar Navigation:** Active state background and indicator bar use `layoutId` with spring physics, creating a fluid animation that follows the user's selection across menu items.

## Background & Atmosphere

The app background is not a simple flat color — it is a **layered atmospheric composition** that provides subtle visual richness:

1. **Base Gradient:** A 135° linear gradient from `#f7fbff` through `#ffffff` to `#f6f9ff`.
2. **Corner Washes:** Four radial gradients placed at each corner — top-left and bottom-right in blue (`rgba(37, 99, 235, 0.18–0.20)`), top-right and bottom-left in warm orange (`rgba(251, 146, 60, 0.18–0.20)`). These fade to transparent within 22–24rem.
3. **Dot Texture (::before):** A fixed-position pseudo-element overlays subtle dot-grid patterns at each corner using `repeating-radial-gradient`, creating a delicate halftone effect at 0.58 opacity.

This three-layer system creates a "living" canvas that shifts subtly as the user scrolls (via `background-attachment: fixed`), reinforcing the premium, polished feel of the platform.
